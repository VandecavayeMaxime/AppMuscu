# AppMuscu

Application Android de suivi de musculation inspirée de Strong. Projet perso et d'apprentissage de Flutter.

## Documentation

- [Spécification fonctionnelle](docs/SPEC.md) : ce que fait l'app
- [Architecture et plan de développement](docs/ARCHITECTURE.md) : comment on la construit
- [Installation de l'environnement](docs/INSTALLATION.md) : Flutter, Android Studio, téléphone

## Commandes utiles

| Commande | Effet |
|---|---|
| `flutter run` | Lance l'app sur le téléphone branché (ou **F5** dans VS Code) |
| `flutter test` | Lance les tests |
| `flutter analyze` | Vérifie le code (erreurs, bonnes pratiques) |
| `flutter pub get` | Télécharge les dépendances du `pubspec.yaml` |
